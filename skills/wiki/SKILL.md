# 에디슬라 위키 스킬

Telegram에서 `/wiki`, `/learn`, `/summary`, `/wstatus` 명령어를 처리하는 스킬.

## Vault 경로 확인

파일 작업 전 반드시 vault 경로를 terminal 도구로 resolve합니다:

```bash
echo ${OBSIDIAN_VAULT_PATH:-/mnt/c/Users/interkm/에디슬라-위키}
```

resolve한 절대경로만 write_file / read_file / search_files 에 전달합니다.
`$OBSIDIAN_VAULT_PATH` 같은 쉘 변수를 파일 도구에 직접 넘기지 마세요.

## 폴더 구조

| 카테고리 | 폴더 경로 |
|---------|----------|
| 프로젝트 | `$VAULT/프로젝트/` |
| 수익모델 | `$VAULT/수익모델/` |
| 기술스택 | `$VAULT/기술스택/` |
| 인사이트 | `$VAULT/인사이트/` |
| 액션아이템 | `$VAULT/액션아이템/` |
| 대화록 | `$VAULT/제니-대화록/` |

폴더가 없으면 먼저 `mkdir -p` 로 생성합니다.

## 파일명 형식

`YYYYMMDD_HHMM_제목.md` — 특수문자는 `_` 치환, 최대 60자

## 노트 마크다운 형식

모든 위키 노트는 아래 형식을 사용합니다:

```
---
date: YYYY-MM-DD
time: HH:MM
category: [카테고리명]
tags: ["태그1", "태그2", "태그3"]
source: hermes-wiki
---

# 제목

#태그1 #태그2

## 요약
- 핵심 포인트 1
- 핵심 포인트 2
- 핵심 포인트 3

## 상세 내용
[마크다운 형식 상세 내용]

## 액션아이템
- [ ] 항목 1
- [ ] 항목 2

---
*자동 생성: YYYY-MM-DD HH:MM by Hermes*
```

## `/wiki [내용]` 처리 방법

사용자가 `/wiki 텍스트` 를 보내면:

1. **분석**: 카테고리, 제목(20자 이내), 태그(2~3개), 요약(bullet 2~3개), 액션아이템 추출
2. **카테고리** — 아래 5개 중 가장 적합한 것 선택:
   - `프로젝트` — 개발/기획/로드맵
   - `수익모델` — 비즈니스/마케팅/수익화
   - `기술스택` — 기술/도구/API/코드
   - `인사이트` — 아이디어/발견/학습
   - `액션아이템` — 할 일/실행 계획
3. **저장**: `write_file` 로 해당 카테고리 폴더에 저장
4. **응답**:

```
✅ 위키 저장 완료

📂 `{카테고리}` | 📌 {제목}
🏷️ #{태그1} #{태그2}
📁 `{파일명}`

• 요약 포인트1
• 요약 포인트2
```

## `/learn [주제]` 처리 방법

사용자가 `/learn 주제` 를 보내면:

1. **학습 문서 생성** — 아래 구조로 작성:
   - `## 개요` — 핵심 설명 2~3문장
   - `## 핵심 개념` — 주요 개념별 설명 (### 소제목 사용)
   - `## 실전 활용` — 코드/사례 예시
   - `## 심화 포인트` — 고급 내용 bullet
   - `## 참고 자료` — 관련 링크/도서
2. **카테고리**: 기본 `기술스택` (내용에 따라 변경 가능)
3. **저장**: `write_file` 로 저장
4. **응답**:

```
✅ 학습 완료

📖 *{주제}*

*핵심 개념*
• 개념1
• 개념2

*액션아이템*
☐ 실습 항목

📁 `{카테고리}/{파일명}`
```

## `/summary` 처리 방법

현재 세션의 대화를 요약해 `제니-대화록/` 폴더에 저장합니다.

파일명: `YYYYMMDD_일일요약.md`

문서 구조:
- `## 오늘의 진행` — 2~3문장 요약
- `## 주요 주제` — bullet list
- `## 핵심 인사이트` — bullet list
- `## 결정사항` — bullet list
- `## 내일 액션아이템` — `- [ ]` 체크박스

---

## `/wstatus` 처리 방법

각 카테고리 폴더의 `.md` 파일 수를 `search_files` 또는 terminal 로 조회해 응답:

```
📊 *Obsidian Wiki 현황*

📁 *프로젝트*: N개
📁 *수익모델*: N개
📁 *기술스택*: N개
📁 *인사이트*: N개
📁 *액션아이템*: N개
📁 *제니-대화록*: N개

📝 총계: N개
🗂️ Vault: /mnt/c/Users/interkm/에디슬라-위키
```

## 중요 규칙

- 파일 도구에 쉘 변수 직접 전달 금지 — vault 경로는 반드시 먼저 resolve해서 절대경로 사용
- 모든 응답은 한국어
- 저장 완료 후 반드시 파일명과 카테고리를 사용자에게 알림
- 텍스트가 짧거나 불명확해도 최선을 다해 분류하여 저장
- 파일 저장 실패 시 오류 메시지와 원인을 한국어로 안내
